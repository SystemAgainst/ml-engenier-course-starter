# Трекер расходов

Консольная программа на Python для учёта расходов. Каждая запись содержит дату, категорию, сумму и комментарий. Программа позволяет просматривать историю, считать общую сумму и суммы по категориям, фильтровать расходы и находить самую крупную транзакцию.

## Запуск

Используется только стандартная библиотека Python.

Из папки `Python Base` в настроенном окружении Poetry:

```bash
poetry run python homework/expense_tracker/main.py
```

Или из папки `homework/expense_tracker`:

```bash
python3 main.py
```

Перед первым запуском рядом с `main.py` должен находиться файл `transactions.json`. Для пустой истории запишите в него `[]`. Если файл уже содержит расходы, сохраните его содержимое.

## Меню

Введите номер действия и нажмите Enter:

| Команда | Действие |
| --- | --- |
| `1` | Показать историю расходов |
| `2` | Добавить новый расход |
| `3` | Показать общую сумму |
| `4` | Показать сводку по категориям |
| `5` | Отфильтровать расходы по категории |
| `6` | Найти самый крупный расход |
| `0` | Сохранить данные и выйти |

После выполнения действия меню появляется снова. При неизвестной команде программа выводит сообщение и предлагает повторить выбор.

## Пример использования

Добавление расхода:

```text
Выбор: 2
Введите дату: 2026-10-25
Введите категорию: Транспорт
Введите сумму: 150.50
Введите описание: Такси
Новая транзакция добавлена
```

Для фильтрации сначала выберите команду `5`, затем введите категорию:

```text
Выбор: 5
Введите категорию: Транспорт
```

Если добавленная запись — единственный расход этой категории, программа покажет:

```text
2026-10-25 | Транспорт | 150.5 | Такси
```

Поиск учитывает регистр: `Транспорт` и `транспорт` — разные категории.

## Правила ввода

- Дата: существующая календарная дата в формате `ГГГГ-ММ-ДД`, например `2026-10-25`.
- Категория: непустое название. Пробелы по краям удаляются.
- Сумма: положительное число. Дробная часть отделяется точкой, например `150.50`.
- Комментарий: произвольный текст, допускается пустая строка.

При неверной дате, пустой категории или ошибке ввода суммы программа повторно запрашивает соответствующее поле.

## Сохранение данных

Данные загружаются из файла `transactions.json` рядом с `main.py`. Путь не зависит от папки запуска программы.

Завершайте работу командой `0`: после выхода из меню программа сохраняет расходы в JSON. При прерывании через Ctrl+C изменения текущего запуска не сохраняются.

Текущая версия ожидает существующий корректный JSON-файл с записями нужной структуры. Ошибки чтения и записи файла отдельно не обрабатываются.
