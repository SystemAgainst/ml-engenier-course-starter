# NumPy-пайплайн подготовки данных

Домашняя работа по подготовке числового датасета с использованием только NumPy.
Pandas и sklearn в работе не используются.

## Что реализовано

- генерация матрицы признаков размером не менее `1000 × 8` и целевого вектора (строки соответствуют объектам, столбцы — признакам);
- фиксация `seed` для воспроизводимости результата;
- добавление пропусков, выбросов и дублирующихся строк;
- удаление дубликатов;
- заполнение пропусков медианами соответствующих столбцов;
- обработка выбросов по выбранному правилу;
- стандартизация признаков;
- перемешивание и разделение данных на train и test без sklearn;
- проверка среднего и стандартного отклонения обработанного train;
- сохранение обработанных данных в файл `.npz`.

## Файлы

- `numpy_pipline.ipynb` — основной Jupyter Notebook с решением;
- `processed_data.npz` — сохранённые обработанные NumPy-массивы;
- `readme.md` — описание домашней работы и инструкция по запуску.

## Установка зависимостей через pip

Создать виртуальное окружение в корне проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установить необходимые библиотеки:

```bash
python -m pip install --upgrade pip
pip install numpy jupyter
```

## Запуск

Из папки `numpy_homework` выполнить:

```bash
jupyter lab
```

Затем открыть файл `numpy_pipline.ipynb` и выполнить ячейки по порядку.

Обязательно после запуска необходимо импортировать библиотеку numpy

```python
import numpy as np
```

## Сохранение результата

Обработанные массивы сохраняются в файл `processed_data.npz`. Его можно загрузить
с помощью NumPy:

```python
data = np.load("processed_data.npz")
X_train = data["X_train"]
X_test = data["X_test"]
y_train = data["y_train"]
y_test = data["y_test"]
```
