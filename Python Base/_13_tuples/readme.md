# Итоги: кортежи (`tuple`)

- Кортеж — упорядоченная коллекция: элементы можно перебирать циклом, проверять наличие через `in`, получать длину через `len()` и обращаться к элементам по индексу.
- Кортеж неизменяем: после создания нельзя заменить, добавить или удалить его элемент. Список (`list`) тоже упорядочен, но изменяем — его элементы можно менять.
- Кортеж из одного элемента создаётся с запятой: `("admin",)`. Без запятой `("admin")` — это строка.
- Распаковка присваивает элементы коллекции отдельным переменным, например `role_1, role_2, role_3 = user_roles`. Она работает и с кортежем, и со списком.
- Если значение при распаковке не нужно, его можно присвоить `_`, например `role_1, role_2, _ = user_roles`.
