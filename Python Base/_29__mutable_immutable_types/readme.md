# Итоги: изменяемые и неизменяемые типы

## Чему я научился

- Переменная хранит ссылку на объект. Присваивание `b = a` не копирует объект.
- `==` сравнивает значения, `is` проверяет, один ли это объект. `id()` помогает увидеть идентичность объектов; не стоит считать его постоянным адресом памяти.
- Изменяемые объекты (`list`, `dict`, `set`) можно менять на месте. Неизменяемые (`int`, `str`, `float`, `bool`, `None` и `tuple`) нельзя изменить после создания.
- `copy()` создаёт поверхностную копию: вложенные изменяемые объекты могут остаться общими. `deepcopy()` рекурсивно копирует вложенные объекты.
- Функция может изменить изменяемый аргумент на месте. Явно решай, должна ли функция менять входные данные или возвращать новый результат.
- Методы с модификацией на месте, например `list.sort()`, обычно меняют исходный список и возвращают `None`; `sorted()` возвращает новый отсортированный список.

## Частые ошибки и как их избежать

| Ошибка | Почему так происходит | Как делать правильно |
|---|---|---|
| Ожидать, что `b = a` создаст копию | Обе переменные ссылаются на один объект; изменение через одну видно через другую | Использовать `a.copy()` для поверхностной копии или `deepcopy(a)` для вложенной структуры |
| Неожиданно изменить список внутри функции | Параметр функции ссылается на тот же изменяемый объект, что и аргумент | Не менять входной объект, если это не часть контракта; при необходимости скопировать данные или вернуть новый объект |
| Использовать `[]` или `{}` как значение параметра по умолчанию | Значение по умолчанию создаётся один раз при определении функции и затем переиспользуется между вызовами | Указывать `None` и создавать новый список/словарь внутри функции |
| Добавлять элементы в коллекцию, по которой сейчас идёт цикл | Цикл может захватывать добавленные элементы и продолжать работу дольше ожидаемого или бесконечно | Сначала создать новую коллекцию, например через генератор списка, затем объединить её с исходной |
| Удалять элементы списка во время обхода этого же списка | После удаления индексы сдвигаются, и следующий элемент может быть пропущен | Создать новый отфильтрованный список или обходить копию списка |
| Ожидать новый список от `list.sort()` | `sort()` сортирует исходный список на месте и возвращает `None` | Использовать `sorted(items)`, если нужен новый список |
| Проверять `None` через `==` или сравнивать boolean с `== True` | Это не проверка идентичности; сравнение с `True` ещё и может дать `True` для значения `1` | Писать `value is None` / `value is not None`; в условии обычно достаточно `if flag:` |

## Пример безопасного значения по умолчанию

```python
def append_to_list(element: int, items: list[int] | None = None) -> list[int]:
    if items is None:
        items = []
    items.append(element)
    return items
```

Каждый вызов без аргумента `items` создаёт новый список. Если список передан явно, функция дополняет именно его.
