# Итоги: область видимости переменных

- Переменная, созданная внутри функции, локальная: доступна только в этой функции и не существует снаружи.
- Функция может читать глобальную переменную, если внутри функции не объявлена локальная переменная с таким же именем. Локальная переменная с тем же именем не изменяет глобальную.
- Ключевое слово `global` позволяет присваивать значение глобальной переменной из функции. Такое изменение влияет на состояние вне функции, поэтому его стоит применять осознанно.
- Переменная цикла `for` остаётся доступной после цикла в Python, но использовать её после цикла обычно не следует: это может затруднить понимание кода.
- Константы принято обозначать именами в верхнем регистре, например `COMFORTABLE_TEMPERATURE` и `DEFAULT_LEVEL_EXPERIENCE`. Функции могут читать эти значения и возвращать результат вычислений, не меняя их.
- Локальные переменные помогают выполнять вычисления внутри функции: например, `is_leveled_up` считает общий опыт и определяет, достигнут ли порог уровня.
