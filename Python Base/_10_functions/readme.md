# Итоги: функции

- Функции (`def`) позволяют оформить повторно используемые действия. Результат функции можно вернуть через `return`; `pass` используется как пустое тело-заглушка.
- Параметры — переменные, указанные в объявлении функции; аргументы — значения, переданные при её вызове. Например, в `def find_average(numbers)` параметр — `numbers`, а в `find_average(numbers_1)` аргумент — список `numbers_1`.
- Функция может принимать аргументы и возвращать вычисленный результат: `find_average` считает среднее значение списка, а `count_volumes` — количество гласных в строке.
- Аннотации типов, например `day: int` и `month: str` в `formate_date`, описывают ожидаемые типы и помогают редактору и анализаторам находить ошибки. Сами по себе они не проверяют типы во время выполнения.
- Аргументы можно передавать позиционно или по имени: `formate_date(day=15, month="October")`. Имена помогают не перепутать порядок.
- `*` в списке параметров делает параметры только именованными. Например, `formate_date2` нужно вызывать как `formate_date2(day=15, month="October")`.
- Параметру можно задать значение по умолчанию. В `custom_greeting` параметр `greeting` по умолчанию равен `"Hello"`, поэтому его можно не указывать: `custom_greeting(name="John")`.
