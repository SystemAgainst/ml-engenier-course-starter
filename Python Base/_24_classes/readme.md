# ООП в Python — краткая шпаргалка

## Основные термины

| Термин | Суть | Пример |
|---|---|---|
| **Класс** | Описание состояния и поведения объектов. | `class Cat: ...` |
| **Экземпляр (объект)** | Конкретное значение, созданное по классу. | `cat = Cat()` |
| **Атрибут** | Данные объекта или класса. Атрибут экземпляра хранит его состояние; атрибут класса задаёт общее значение. | `self.name`, `species = "cat"` |
| **Метод** | Функция в классе; метод экземпляра получает объект первым аргументом (`self`). | `cat.speak()` вызывает `Cat.speak(cat)` |
| **Свойство** | Атрибутный интерфейс к вычислению или контролируемому доступу к данным. `@property` читается без `()`. | `cat.age` |
| **Инкапсуляция** | Состояние и операции над ним объединены в объект; детали скрыты за его интерфейсом. В Python `_name` — соглашение о непубличном атрибуте, `__name` включает name mangling, но не обеспечивает безопасность. | `cat._age`; публичное свойство `cat.age` |
| **Абстракция** | Показать существенный интерфейс, скрыв детали реализации. Абстрактный класс задаёт обязательные операции. | `@abstractmethod def area(self): ...` |
| **Наследование** | Подкласс получает и специализирует поведение базового класса. | `class Dog(Animal): ...` |
| **Полиморфизм** | Один интерфейс — разное поведение объектов разных типов; обычно достигается переопределением метода. | `animal.speak()` вызывает реализацию `Dog` или `Cat` |

### Методы и свойства: разница

- **Метод** — действие; вызывается со скобками, может принимать аргументы: `user.reset_password()`.
- **Свойство** — значение/характеристика; читается как атрибут: `user.full_name`.
- Свойство уместно для дешёвого и понятного вычисления или контроля доступа. Не скрывайте за ним тяжёлую операцию с неожиданными побочными эффектами.

```python
class Animal:
    def __init__(self, name: str) -> None:
        self._name = name

    @property
    def name(self) -> str:
        return self._name

    def speak(self) -> str:
        return "..."


class Dog(Animal):
    def speak(self) -> str:
        return "woof"
```

В примере `Animal` — класс, `Dog` наследуется от него и переопределяет метод. Вызов `animal.speak()` работает через общий интерфейс, а конкретная реализация выбирается по типу экземпляра. `name` — свойство, `speak()` — метод.

## `super()` и MRO

- **MRO (Method Resolution Order)** — порядок, в котором Python ищет атрибуты и методы по классу и его базовым классам. Посмотреть порядок можно через `ClassName.__mro__`.
- **`super()`** обращается к следующему классу в MRO, а не обязательно напрямую к родителю. Используйте его для кооперативного вызова реализации базового класса, в том числе при множественном наследовании.
- В простом наследовании `super().method()` обычно вызывает реализацию родителя; в цепочке наследования каждый класс может продолжить вызов через `super()`.

```python
class Dog(Animal):
    def __init__(self, name: str, breed: str) -> None:
        super().__init__(name)
        self.breed = breed
```

## Что помнить

- `self` — соглашение об имени ссылки на текущий экземпляр; при `obj.method()` передаётся автоматически.
- `__init__` инициализирует созданный экземпляр, обычно задавая его начальное состояние; создание выполняется до него.
- Атрибуты экземпляра принадлежат объекту, атрибуты класса разделяются через поиск по классу и MRO. Изменяемое состояние экземпляров не следует хранить в изменяемом атрибуте класса.
- Python поддерживает инкапсуляцию соглашениями и интерфейсами, но `_attribute` не является строгим запретом доступа.
- Аннотации типов сами по себе не проверяют значения во время выполнения.

## 10. Короткие ответы для собеседования

**Чем класс отличается от экземпляра?**

Класс задаёт структуру и поведение, экземпляр хранит конкретное состояние и использует это поведение.

**Что такое `self`?**

Ссылка на текущий экземпляр, передаваемая автоматически при вызове метода через экземпляр. Это соглашение по имени, а не ключевое слово.

**Чем атрибут класса отличается от атрибута экземпляра?**

Атрибут класса принадлежит объекту-классу и обычно задаёт общую конфигурацию. Атрибут экземпляра относится к конкретному объекту. При поиске атрибута Python проверяет экземпляр, класс и далее MRO.

**Что делает `__init__`?**

Инициализирует уже созданный экземпляр; обычно присваивает начальное состояние. Создание объекта инициализатором не ограничивается: сначала вызывается механизм `__new__`.

**Что такое переопределение и полиморфизм?**

Подкласс предоставляет свою реализацию метода базового класса. Один и тот же вызов через общий интерфейс (`character.attack(...)`) приводит к реализации, соответствующей фактическому типу объекта.

**Для чего нужен `super()`?**

Чтобы продолжить поиск реализации по MRO и вызвать следующую реализацию метода или свойства, не привязываясь жёстко к имени конкретного родительского класса.

**Когда подходит `@property`?**

Когда значение логично читать как атрибут, но его нужно вычислить или контролировать доступ к нему. В примере максимум HP и защита вычисляются из уровня и базовых характеристик.

**Почему `print(method())` может напечатать `None`?**

Потому что метод может сам печатать результат, но ничего не возвращать. Тогда `print` получает возвращённое значение `None` и тоже его выводит.
