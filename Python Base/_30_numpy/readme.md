**NumPy — шпаргалка по основам**

NumPy — библиотека Python для вычислений с массивами. Она позволяет выполнять одну операцию над большим количеством чисел, выбирать данные по условиям и работать с матрицами. Главные темы для понимания: форма массива, тип элементов, оси, индексация и совместимость форм.

Текст использует короткие предложения, постоянные термины и явные условия. Это адаптация принципов ASD-STE100 для русского языка, а не формальное соответствие стандарту. Примеры рассчитаны на NumPy 2.x.

**2. Массив: основной объект NumPy**

**Массив** — объект `np.ndarray`, который хранит элементы одного типа и описывает их расположение по осям. **Ось** — направление, вдоль которого можно выбирать элементы по индексу. **Индекс** — номер позиции элемента. Индексы начинаются с нуля.

```python
a = np.array([10, 20, 30])

a[0]   # 10
a[2]   # 30
a[-1]  # 30: последний элемент
```

**Форма массива** — количество элементов вдоль каждой оси. Она записывается как кортеж. Например, форма `(2, 3)` означает две строки и три столбца.

```text
Массив формы (2, 3)

              столбцы: ось 1
                0   1   2
              ┌───────────┐
строки:     0 │ 10  20  30│
ось 0       1 │ 40  50  60│
              └───────────┘
```

**Скаляр** — одно значение. Одномерный массив имеет одну ось. Двумерный массив имеет две оси. Массивы с большим количеством осей позволяют хранить, например, группы изображений.

```python
scalar = np.array(7)                      # shape: ()
vector = np.array([1, 2, 3])              # shape: (3,)
matrix = np.array([[1, 2, 3], [4, 5, 6]])  # shape: (2, 3)
batch = np.zeros((10, 28, 28))            # 10 изображений 28 × 28
```

Обычный числовой массив должен иметь прямоугольную структуру. В двумерном массиве все строки имеют одинаковую длину. Для строк разной длины используйте другую структуру данных. [Основы массивов](https://numpy.org/doc/stable/user/absolute_beginners)

**3. Чем массив отличается от списка**

Арифметика с массивами обычно выполняется **поэлементно**: операция применяется к каждому элементу. У списков Python операторы `+` и `*` имеют другое значение.

```python
[1, 2, 3] + [4, 5, 6]  # [1, 2, 3, 4, 5, 6]
[1, 2, 3] * 2           # [1, 2, 3, 1, 2, 3]

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

a + b  # [5, 7, 9]
a * 2  # [2, 4, 6]
```

**Векторизация** — запись вычисления через операции над целыми массивами вместо явного цикла Python. Такие операции часто быстрее для больших числовых массивов. Скорость зависит от размера данных, типа элементов и выделения памяти.

```python
a = np.array([1, 2, 3])

# Цикл Python.
result = [x ** 2 for x in a]

# Векторизация.
result = a ** 2
```

`np.vectorize()` помогает применять обычную функцию к элементам массива. Однако сама по себе эта функция не превращает вычисление в быстрый машинный код. Для ускорения сначала ищите готовую операцию NumPy. [Краткое руководство](https://numpy.org/doc/stable/user/quickstart)

**4. Свойства массива**

Проверяйте форму, количество осей и тип элементов перед вычислениями. Эти свойства помогают объяснить большинство ошибок.

```python
a = np.array(
    [[1, 2, 3],
     [4, 5, 6]],
    dtype=np.int64,
)
```

| Свойство | Значение | Что означает |
|---|---:|---|
| `a.shape` | `(2, 3)` | Форма |
| `a.ndim` | `2` | Количество осей |
| `a.size` | `6` | Общее количество элементов |
| `a.dtype` | `int64` | Тип элементов |
| `a.itemsize` | `8` | Количество байтов на элемент |
| `a.nbytes` | `48` | Объём данных элементов в байтах |

`len(a)` возвращает длину первой оси, а не общее количество элементов. Для этого массива `len(a)` равно `2`, а `a.size` равно `6`. У массива без осей вызов `len()` вызывает ошибку.

`a.nbytes` не описывает весь расход памяти объекта Python. Для массивов с типом `object` он также не включает память объектов, на которые ссылаются элементы. [Краткое руководство](https://numpy.org/doc/stable/user/quickstart)

**5. Создание массивов**

Выбирайте функцию создания по тому, какие начальные значения нужны.

```python
np.array([1, 2, 3])       # Из последовательности
np.zeros((2, 3))          # Нули
np.ones((2, 3))           # Единицы
np.full((2, 3), 7)        # Указанное значение
np.eye(3)                # Единицы на главной диагонали, остальные — нули

np.zeros_like(a)         # Форма и тип как у a, значения — нули
np.ones_like(a)          # Форма и тип как у a, значения — единицы
```

`np.empty()` выделяет массив без заполнения числовых элементов заданными значениями. Не считайте его содержимое нулями или случайными числами. Запишите все элементы до чтения.

```python
buffer = np.empty((2, 3))
buffer[:] = 0
```

`np.asarray()` преобразует входные данные в массив и по возможности использует существующие данные без копирования. `np.array()` по умолчанию создаёт копию при получении обычного массива.

```python
a = np.array([1, 2, 3])

b = np.asarray(a)  # Здесь b — тот же объект, что и a
c = np.array(a)    # Независимая копия данных
```

`np.arange()` создаёт значения с заданным шагом. Правая граница не входит в диапазон. Для дробного шага возможны эффекты округления.

```python
np.arange(5)        # [0, 1, 2, 3, 4]
np.arange(2, 10, 2) # [2, 4, 6, 8]
```

`np.linspace()` создаёт заданное количество равномерно расположенных значений. Правая граница входит в диапазон по умолчанию.

```python
np.linspace(0, 1, 5)  # [0.0, 0.25, 0.5, 0.75, 1.0]
```

Схема выбора:

```text
Есть готовые данные → array / asarray
Нужно заполнение   → zeros / ones / full
Известен шаг       → arange
Известно число точек → linspace
```

[Создание массивов](https://numpy.org/doc/stable/reference/routines.array-creation.html)

**6. Тип элементов: `dtype`**

**Тип элементов**, или `dtype`, определяет способ хранения значений. Он влияет на допустимый диапазон, точность и расход памяти.

| Тип | Назначение |
|---|---|
| `np.bool_` | Значения `True` и `False` |
| `np.int32` | Целые числа, 32 бита |
| `np.int64` | Целые числа, 64 бита |
| `np.float32` | Числа с плавающей точкой, 32 бита |
| `np.float64` | Числа с плавающей точкой, 64 бита |
| `np.complex128` | Комплексные числа |
| `object` | Ссылки на объекты Python |

**Число с плавающей точкой** — приближённое представление числа с дробной частью. `float64` обычно даёт больше точности, чем `float32`, но занимает вдвое больше памяти.

```python
a = np.array([1, 2, 3], dtype=np.float64)
```

`astype()` преобразует тип элементов. По умолчанию оно создаёт новый массив. Преобразование дробных значений в целые отбрасывает дробную часть по направлению к нулю.

```python
a = np.array([1.9, -2.7])
b = a.astype(np.int64)

# b: [1, -2]
```

Целые типы NumPy имеют ограниченный диапазон. **Переполнение** возникает, когда результат не помещается в этот диапазон. Не рассчитывайте на автоматическое расширение типа, как у целых чисел Python.

```python
np.iinfo(np.int32).max  # Максимальное значение int32
np.finfo(np.float64).eps  # Шаг от 1.0 к следующему большему числу
```

[Типы данных](https://numpy.org/doc/stable/user/basics.types.html)

**7. Смешивание типов и изменение на месте**

NumPy определяет тип результата по типам операндов и правилам операции. Не предполагайте, что добавление числа Python обязательно повысит точность массива.

```python
a = np.array([1, 2], dtype=np.int64)

a + 0.5  # [1.5, 2.5]
a / 2    # [0.5, 1.0]
```

**Изменение на месте** — запись результата в существующий массив. При `+=`, `*=`, `/=` тип существующего массива ограничивает допустимый результат.

```python
a = np.array([1, 2, 3], dtype=np.int64)

# a += 0.5
# Ошибка: результат с дробной частью нельзя записать
# в этот массив по правилам данной операции.

a = a + 0.5  # Новый массив с подходящим типом
```

Прямое присваивание может преобразовать значение с потерей дробной части. Поэтому проверяйте `dtype` до записи.

```python
a = np.array([1, 2, 3], dtype=np.int64)
a[0] = 1.9

# a: [1, 2, 3]
```

[Правила определения типа результата](https://numpy.org/doc/stable/reference/arrays.promotion.html)

**8. Индексы и срезы**

**Срез** — выбор элементов по правилу `start:stop:step`. Граница `stop` не входит в результат.

```python
a = np.array([10, 20, 30, 40, 50])

a[1]     # 20
a[1:4]   # [20, 30, 40]
a[:3]    # [10, 20, 30]
a[2:]    # [30, 40, 50]
a[::2]   # [10, 30, 50]
a[::-1]  # [50, 40, 30, 20, 10]
```

Для нескольких осей разделяйте индексы запятыми. Порядок индексов соответствует порядку осей.

```python
a = np.array([
    [10, 20, 30],
    [40, 50, 60],
])

a[1, 2]    # 60
a[0, :]    # [10, 20, 30]
a[:, 1]    # [20, 50]
a[:, 1:]   # [[20, 30], [50, 60]]
```

Целочисленный индекс убирает соответствующую ось. Срез сохраняет её.

```python
a[0].shape     # (3,)
a[0:1].shape   # (1, 3)

a[:, 0].shape    # (2,)
a[:, 0:1].shape  # (2, 1)
```

`...` означает все неуказанные оси. Это удобно для массивов с несколькими осями.

```python
images = np.zeros((10, 28, 28, 3))
red = images[..., 0]

red.shape  # (10, 28, 28)
```

[Индексация](https://numpy.org/doc/stable/user/basics.indexing.html)

**9. Представления и копии**

**Представление** — массив, который использует данные другого массива. Изменение общих элементов через представление изменяет исходные данные.

```python
a = np.array([10, 20, 30, 40])

b = a[1:3]
b[0] = 999

# a: [10, 999, 30, 40]
```

**Копия** — массив с независимыми данными. Для обычных числовых массивов `.copy()` позволяет изменять результат без изменения исходного массива.

```python
a = np.array([10, 20, 30, 40])

b = a[1:3].copy()
b[0] = 999

# a: [10, 20, 30, 40]
```

Присваивание `b = a` создаёт ещё одно имя для того же объекта. Оно не создаёт ни представление, ни копию массива.

```text
b = a          → тот же объект     → те же данные
b = a[1:3]     → новый объект      → общие данные
b = a.copy()   → новый объект      → отдельные данные
```

Обычные срезы возвращают представления. Выбор по массиву индексов или логической маске возвращает копию. `reshape()` может вернуть представление или потребовать копирование.

```python
np.shares_memory(a, b)  # Есть ли общая память?
```

У массива с типом `object` копирование массива не копирует вложенные объекты Python. В копии остаются ссылки на те же объекты. [Копии и представления](https://numpy.org/doc/stable/user/basics.copies.html)

**10. Выбор по массиву индексов**

Массив целочисленных индексов позволяет выбрать элементы в заданном порядке. Индексы можно повторять.

```python
a = np.array([10, 20, 30, 40])

a[[3, 0, 3]]  # [40, 10, 40]
```

Несколько массивов индексов выбирают координаты попарно. Для всех сочетаний строк и столбцов используйте `np.ix_()`.

```python
a = np.array([
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90],
])

a[[0, 2], [1, 2]]  # [20, 90]: координаты (0, 1) и (2, 2)

a[np.ix_([0, 2], [1, 2])]
# [[20, 30],
#  [80, 90]]
```

Присваивание через индекс изменяет исходный массив. Но изменение предварительно извлечённой копии его не изменяет.

```python
a = np.array([10, 20, 30])

a[[0, 2]] = 0  # a: [0, 20, 0]

b = a[[0, 2]]
b[:] = 99      # a остаётся [0, 20, 0]
```

[Расширенная индексация](https://numpy.org/doc/stable/user/basics.indexing.html)

**11. Условия и логические маски**

**Логическая маска** — массив значений `True` и `False`. При выборе по маске NumPy оставляет позиции со значением `True`.

```python
a = np.array([10, 20, 30, 40])

mask = a >= 25  # [False, False, True, True]

a[mask]        # [30, 40]
a[mask] = 0    # a: [10, 20, 0, 0]
```

Соединяйте поэлементные условия операторами `&`, `|` и `~`. Каждое сравнение заключайте в скобки.

```python
a = np.array([10, 20, 30, 40])

a[(a >= 20) & (a < 40)]  # [20, 30]
a[(a < 20) | (a > 30)]   # [10, 40]
a[~(a > 20)]            # [10, 20]
```

Для проверки всего условия используйте `np.any()` или `np.all()`. `any` отвечает, есть ли хотя бы одно истинное значение. `all` отвечает, все ли значения истинны.

```python
np.any(a > 30)  # True
np.all(a > 0)   # True

if np.any(a < 0):
    print("Есть отрицательные значения")
```

Не используйте `and`, `or` и обычный `if mask` для поэлементной проверки многоэлементного массива: его истинность неоднозначна. [Выбор по условиям](https://numpy.org/doc/stable/user/absolute_beginners)

**12. Поэлементные вычисления**

Арифметические операторы применяются к соответствующим элементам массивов. Умножение `*` также выполняется поэлементно.

```python
a = np.array([2, 4, 6])
b = np.array([1, 2, 3])

a + b   # [3, 6, 9]
a - b   # [1, 2, 3]
a * b   # [2, 8, 18]
a / b   # [2.0, 2.0, 2.0]
a // b  # [2, 2, 2]
a % b   # [0, 0, 0]
a ** 2  # [4, 16, 36]
```

**Универсальная функция**, или `ufunc`, — функция NumPy, которая применяет операцию поэлементно и поддерживает правила совместимости форм. Примеры: `np.sqrt()`, `np.exp()` и `np.add()`.

```python
np.sqrt([1, 4, 9])       # Квадратный корень
np.abs([-2, 0, 3])       # Модуль
np.exp([0.0, 1.0])       # Экспонента
np.log([1.0, np.e])      # Натуральный логарифм
np.sin([0.0, np.pi / 2]) # Синус; аргумент в радианах

np.minimum([1, 5], [3, 2])  # [1, 2]
np.maximum([1, 5], [3, 2])  # [3, 5]
np.clip([-2, 5, 12], 0, 10) # [0, 5, 10]
```

Проверяйте область допустимых значений. Например, `np.log(0.0)` даёт отрицательную бесконечность, а `np.sqrt(-1.0)` для вещественного типа даёт `NaN`. По умолчанию такие операции обычно сопровождаются предупреждением. [Математические функции](https://numpy.org/doc/stable/reference/routines.math.html)

**13. Broadcasting: совместимость форм**

**Broadcasting** — правило, по которому NumPy выполняет операции над массивами разных форм. Оси сравниваются справа налево. Длины совместимы, если они равны или одна из них равна `1`. Отсутствующие слева оси считаются осями длины `1`.

```text
Форма A:            (2, 3)
Форма B:               (3,)
Дополнение формы B: (1, 3)
Результат:          (2, 3)
```

```python
a = np.array([
    [1, 2, 3],
    [4, 5, 6],
])

b = np.array([10, 20, 30])

a + b
# [[11, 22, 33],
#  [14, 25, 36]]
```

Для прибавления отдельного числа к каждой строке используйте форму `(число_строк, 1)`.

```python
offset = np.array([10, 20])

a + offset[:, None]
# [[11, 12, 13],
#  [24, 25, 26]]
```

Формы `(2, 3)` и `(2,)` несовместимы: справа сравниваются длины `3` и `2`. Ни одна из них не равна `1`.

```text
1. Выровнять формы справа.
             ↓
2. Сравнить длины каждой пары осей.
             ↓
3. Если длины равны или одна равна 1 — продолжить.
             ↓
4. Иначе операция невозможна.
```

Broadcasting обычно не создаёт физические копии повторяемого входного массива. Однако результат может занимать много памяти. Например, операция между формами `(100000, 1)` и `(1, 100000)` создаёт результат из десяти миллиардов элементов. [Broadcasting](https://numpy.org/doc/stable/user/basics.broadcasting.html)

**14. Изменение формы и порядка осей**

`reshape()` меняет форму без изменения количества элементов. Значение `-1` поручает NumPy вычислить одну длину автоматически. Допускается только одно значение `-1`.

```python
a = np.arange(12)

a.reshape(3, 4).shape   # (3, 4)
a.reshape(2, -1).shape  # (2, 6)

# a.reshape(5, 3)  # Ошибка: 12 элементов не заполнят 15 позиций
```

`None`, или `np.newaxis`, добавляет ось длины `1`. Одномерный массив сам по себе не является ни строкой формы `(1, n)`, ни столбцом формы `(n, 1)`.

```python
v = np.array([1, 2, 3])

v.shape           # (3,)
v[None, :].shape  # (1, 3)
v[:, None].shape  # (3, 1)
```

`squeeze()` удаляет оси длины `1`. Указывайте `axis`, если нужно удалить конкретную ось и проверить её длину.

```python
a = np.zeros((1, 3, 1))

a.squeeze().shape        # (3,)
a.squeeze(axis=0).shape  # (3, 1)
```

**Транспонирование** меняет порядок осей. Для двумерного массива `.T` меняет строки и столбцы местами. Для массива с большим количеством осей `.T` разворачивает порядок всех осей.

```python
a = np.zeros((2, 3))
a.T.shape  # (3, 2)

b = np.zeros((2, 3, 4))
b.transpose(1, 0, 2).shape  # (3, 2, 4)
```

`ravel()` возвращает одномерный массив и копирует данные только при необходимости. `flatten()` всегда создаёт копию.

```text
reshape   → изменить форму
transpose → переставить оси
ravel     → получить одну ось
```

[Изменение массивов](https://numpy.org/doc/stable/reference/routines.array-manipulation.html)

**15. Агрегация и параметр `axis`**

**Агрегация** — вычисление итогового значения по группе элементов. Примеры: сумма, среднее и максимум. Без `axis` многие такие функции обрабатывают весь массив.

```python
a = np.array([
    [1, 2, 3],
    [4, 5, 6],
])

a.sum()   # 21
a.mean()  # 3.5
a.min()   # 1
a.max()   # 6
```

В агрегации параметр `axis` задаёт ось, вдоль которой объединяются элементы. По умолчанию эта ось исчезает из формы результата.

```python
a.sum(axis=0)  # [5, 7, 9]: сумма каждого столбца
a.sum(axis=1)  # [6, 15]: сумма каждой строки
```

```text
Исходный массив:       (2, 3)
sum(axis=0):           (3,)    — убрать ось 0
sum(axis=1):           (2,)    — убрать ось 1
sum():                 ()      — объединить все элементы
```

`keepdims=True` сохраняет обработанную ось с длиной `1`. Это помогает использовать результат в broadcasting.

```python
row_mean = a.mean(axis=1, keepdims=True)

row_mean.shape  # (2, 1)
a - row_mean   # Из каждой строки вычесть её среднее
```

Для нескольких осей передайте кортеж. Отрицательный номер оси отсчитывается с конца: `axis=-1` означает последнюю ось.

```python
x = np.ones((2, 3, 4))

x.sum(axis=(1, 2)).shape  # (2,)
x.sum(axis=-1).shape     # (2, 3)
```

[Агрегация по осям](https://numpy.org/doc/stable/user/quickstart)

**16. Статистика**

Выбирайте статистическую функцию по смыслу результата.

| Функция | Результат |
|---|---|
| `np.mean(a)` | Среднее арифметическое |
| `np.median(a)` | Медиана: центральное значение упорядоченных данных |
| `np.var(a)` | Дисперсия |
| `np.std(a)` | Стандартное отклонение |
| `np.quantile(a, 0.25)` | Квантиль уровня `0.25` |
| `np.percentile(a, 25)` | То же через шкалу от `0` до `100` |
| `np.average(a, weights=w)` | Среднее с весами |

**Дисперсия** измеряет средний квадрат отклонения от среднего. **Стандартное отклонение** — квадратный корень из дисперсии. Оно имеет те же единицы измерения, что и данные.

По умолчанию `var()` и `std()` используют делитель `N`, где `N` — количество элементов в обрабатываемой группе. Параметр `ddof` меняет делитель на `N - ddof`.

```python
a = np.array([1.0, 2.0, 3.0])

np.var(a, ddof=0)  # Делитель N
np.var(a, ddof=1)  # Делитель N - 1
```

`ddof=1` часто используют для оценки дисперсии генеральной совокупности по выборке. При этом число элементов должно быть больше `1`. Такая поправка не делает стандартное отклонение автоматически несмещённой оценкой.

**Квантиль** задаёт границу распределения для указанной доли данных. При небольшом количестве элементов результат зависит от метода интерполяции; его можно задать через `method`. [Статистические функции](https://numpy.org/doc/stable/reference/routines.statistics.html)

**17. `NaN`, бесконечности и пропуски**

`NaN` — специальное значение с плавающей точкой, которое обозначает неопределённый числовой результат. Его также часто используют для пропусков. `np.inf` и `-np.inf` обозначают положительную и отрицательную бесконечность.

```python
a = np.array([1.0, np.nan, np.inf, -np.inf])

np.isnan(a)    # [False, True, False, False]
np.isinf(a)    # [False, False, True, True]
np.isfinite(a) # [True, False, False, False]
```

Проверяйте `NaN` через `np.isnan()`. Сравнение `NaN` с самим собой через `==` возвращает `False`.

```python
np.nan == np.nan  # False

finite_values = a[np.isfinite(a)]
```

Функции с префиксом `nan` пропускают `NaN`, но не обязательно бесконечности. Например, `np.nanmean()` игнорирует `NaN`; бесконечности остаются частью вычисления.

```python
a = np.array([1.0, np.nan, 3.0])

np.mean(a)     # nan
np.nanmean(a)  # 2.0
np.nanstd(a)   # 1.0
```

Если вся обрабатываемая группа состоит из `NaN`, `np.nanmean()` возвращает `NaN` и выдаёт предупреждение. Не считайте пропуски нулями без основания. [Статистика с пропусками](https://numpy.org/doc/stable/reference/routines.statistics.html)

**18. Сравнение дробных значений**

Используйте `np.isclose()` для приближённого сравнения чисел с плавающей точкой. Точное сравнение через `==` может не пройти из-за округления.

```python
0.1 + 0.2 == 0.3           # False
np.isclose(0.1 + 0.2, 0.3) # True
```

Для конечных значений `np.isclose(a, b)` проверяет условие `abs(a - b) <= atol + rtol * abs(b)`. Здесь `atol` — абсолютный допуск, а `rtol` — относительный допуск. Значение `b` служит опорным, поэтому проверка не обязана быть симметричной.

```python
np.isclose(
    [1.0, 2.0],
    [1.000001, 2.000001],
    rtol=1e-5,
    atol=1e-8,
)
```

`np.allclose()` возвращает одно логическое значение для всей проверки. Выбирайте допуски по масштабу данных, особенно около нуля. При необходимости отдельно проверьте формы: сравнение поддерживает broadcasting.

```python
a = np.array([1.0, 2.0])
b = np.array([1.0, 2.0])

same = a.shape == b.shape and np.allclose(a, b)
```

Для точного сравнения формы и элементов используйте `np.array_equal()`. Чтобы считать `NaN` на одинаковых позициях равными, передайте `equal_nan=True`. [Приближённое сравнение](https://numpy.org/doc/stable/reference/generated/numpy.isclose.html)

**19. Выбор значений через `where`**

`np.where(condition, x, y)` выбирает элементы из `x`, где условие истинно, и из `y`, где оно ложно. Формы трёх аргументов должны быть совместимы по broadcasting.

```python
a = np.array([-3, 0, 5])

np.where(a > 0, a, 0)  # [0, 0, 5]
```

`np.where()` не откладывает вычисление ветвей. В выражении `np.where(a != 0, 1 / a, 0)` Python сначала вычислит `1 / a`, включая деление на ноль.

Для условного деления используйте параметр `where` у `np.divide()`. Заранее заполните выходной массив: позиции с ложным условием сохраняют прежние значения.

```python
a = np.array([0.0, 2.0, 4.0])
result = np.zeros_like(a)

np.divide(1.0, a, out=result, where=a != 0)

# result: [0.0, 0.5, 0.25]
```

```text
Создать выходной массив
          ↓
Вычислить маску допустимых позиций
          ↓
Выполнить операцию только в этих позициях
```

[Выбор через `where`](https://numpy.org/doc/stable/reference/generated/numpy.where.html)

**20. Объединение и разделение**

`np.concatenate()` объединяет массивы вдоль существующей оси. Длины всех остальных осей должны совпадать.

```python
a = np.array([[1, 2], [3, 4]])
b = np.array([[5, 6]])

np.concatenate([a, b], axis=0)
# [[1, 2],
#  [3, 4],
#  [5, 6]]
```

`np.stack()` создаёт новую ось. Все входные массивы должны иметь одинаковую форму.

```python
a = np.array([1, 2])
b = np.array([3, 4])

np.concatenate([a, b]).shape  # (4,)
np.stack([a, b], axis=0).shape # (2, 2)
```

`np.split()` делит массив на равные части, если передано число частей. Если равное деление невозможно, возникает ошибка. `np.array_split()` допускает части разной длины.

```python
a = np.arange(7)

parts = np.array_split(a, 3)
# [array([0, 1, 2]), array([3, 4]), array([5, 6])]
```

`np.append()` возвращает новый массив. Не используйте многократный `append()` как основной способ накопления больших данных: каждое расширение требует нового массива. Накапливайте части в списке и объединяйте один раз. [Объединение и разделение](https://numpy.org/doc/stable/reference/routines.array-manipulation.html)

**21. Сортировка, поиск и подсчёт**

`np.sort()` возвращает отсортированную копию. Метод `a.sort()` сортирует сам массив и возвращает `None`. Для многомерного массива по умолчанию сортируется последняя ось.

```python
a = np.array([30, 10, 20])

b = np.sort(a)  # b: [10, 20, 30]; a не изменён
a.sort()       # a: [10, 20, 30]
```

`np.argsort()` возвращает индексы, которые задают порядок сортировки. Это удобно для согласованного изменения нескольких массивов.

```python
scores = np.array([80, 95, 70])
names = np.array(["Анна", "Борис", "Вера"])

order = np.argsort(scores)

scores[order]  # [70, 80, 95]
names[order]   # ["Вера", "Анна", "Борис"]
```

`argmin()` и `argmax()` возвращают индексы минимального и максимального значений. Без `axis` индекс относится к развёрнутому массиву. При нескольких одинаковых экстремумах возвращается первое в соответствующем порядке вхождение.

```python
a = np.array([4, 9, 2])

a.argmin()  # 2
a.argmax()  # 1
```

`np.nonzero()` возвращает индексы ненулевых элементов отдельно для каждой оси. `np.count_nonzero()` возвращает их количество.

```python
a = np.array([0, 5, 0, 8])

np.nonzero(a)       # (array([1, 3]),)
np.count_nonzero(a) # 2
```

[Сортировка и поиск](https://numpy.org/doc/stable/reference/routines.sort.html)

**22. Повторяющиеся индексы при накоплении**

a[[0, 0, 1]] += 1

# a: [1, 1, 0], а не [2, 1, 0]

**23. Случайные числа**

Создайте **генератор случайных чисел** через `np.random.default_rng()`. Это объект, который хранит состояние последовательности и создаёт новые значения при каждом вызове.

```python
rng = np.random.default_rng(42)

rng.random((2, 3))            # Равномерные значения из [0, 1)
rng.integers(0, 10, size=5)    # Целые значения от 0 до 9
rng.normal(0, 1, size=5)       # Нормальное распределение
```

**Начальное значение**, или `seed`, задаёт исходное состояние генератора. Одинаковое начальное значение и одинаковая последовательность вызовов дают воспроизводимый результат в одинаковых условиях. NumPy не гарантирует неизменность всех последовательностей `Generator` между версиями.

```python
rng1 = np.random.default_rng(42)
rng2 = np.random.default_rng(42)

np.array_equal(rng1.random(5), rng2.random(5))  # True
```

`choice()` выбирает элементы. При `replace=False` одна и та же позиция не выбирается повторно; размер выборки не может превышать число доступных позиций.

```python
rng.choice([10, 20, 30, 40], size=2, replace=False)
```

`permutation()` возвращает перемешанную копию. `shuffle()` изменяет переданный массив на месте. Для многомерных массивов по умолчанию перемешиваются позиции вдоль первой оси.

```python
a = np.arange(5)

b = rng.permutation(a)
rng.shuffle(a)
```

[Генератор случайных чисел](https://numpy.org/doc/stable/reference/random/generator.html)

**24. Матрицы и линейная алгебра**

Для матриц используйте обычные двумерные массивы. Оператор `@` выполняет матричное умножение. Для форм `(m, k)` и `(k, n)` результат имеет форму `(m, n)`.

```text
A: (m, k)  @  B: (k, n)
         общая длина k
                ↓
Результат: (m, n)
```

```python
A = np.array([
    [1, 2],
    [3, 4],
])

B = np.array([
    [10, 20],
    [30, 40],
])

A * B
# [[10, 40],
#  [90, 160]]

A @ B
# [[70, 100],
#  [150, 220]]
```

Для двух одномерных массивов одинаковой длины `@` вычисляет **скалярное произведение** — сумму произведений соответствующих элементов.

```python
x = np.array([1, 2, 3])
y = np.array([4, 5, 6])

x @ y  # 32
```

Для решения системы `A @ x = b` используйте `np.linalg.solve(A, b)`. Матрица `A` должна быть квадратной и невырожденной, то есть иметь единственное решение для каждого `b`.

```python
A = np.array([[2.0, 0.0], [0.0, 4.0]])
b = np.array([6.0, 8.0])

x = np.linalg.solve(A, b)  # [3.0, 2.0]
```

Не вычисляйте обратную матрицу только ради решения системы. Для прямоугольных систем или приближённого решения используйте `np.linalg.lstsq()`. Почти вырожденная система может дать неточный результат даже без ошибки. [Линейная алгебра](https://numpy.org/doc/stable/reference/routines.linalg.html)

**25. Сохранение и загрузка**

Используйте `.npy` для одного массива. Этот формат сохраняет форму и тип элементов.

```python
a = np.array([[1, 2], [3, 4]])

np.save("array.npy", a)
loaded = np.load("array.npy", allow_pickle=False)
```

Используйте `.npz` для нескольких именованных массивов. После чтения закройте архив через `with`.

```python
np.savez_compressed("dataset.npz", features=a, targets=np.array([0, 1]))

with np.load("dataset.npz", allow_pickle=False) as data:
    features = data["features"]
    targets = data["targets"]
```

Для простых числовых CSV-файлов используйте `savetxt()` и `loadtxt()`. Текстовый формат не сохраняет тип и форму так же полно, как `.npy`.

```python
np.savetxt("array.csv", a, delimiter=",", fmt="%d")
loaded = np.loadtxt("array.csv", delimiter=",", dtype=np.int64)
```

Для текстовых данных с пропусками предусмотрен `np.genfromtxt()`. Для сложных таблиц со смешанными столбцами обычно удобнее специализированная табличная библиотека.

Не включайте `allow_pickle=True` для недоверенных файлов: загрузка объектов через pickle может выполнять код. Обычным числовым массивам pickle не нужен. [Чтение и запись](https://numpy.org/doc/stable/reference/routines.io.html)

**26. Пример: стандартизация признаков**

**Стандартизация** — преобразование, при котором из значения вычитают среднее и делят результат на стандартное отклонение. В таблице признаков строки обычно обозначают объекты, а столбцы — признаки.

```text
X: строки — объекты, столбцы — признаки
                    ↓
Среднее каждого столбца
                    ↓
Стандартное отклонение каждого столбца
                    ↓
Вычесть среднее и разделить на отклонение
```

```python
X = np.array([
    [10.0, 100.0, 5.0],
    [20.0, 200.0, 5.0],
    [30.0, 300.0, 5.0],
])

mean = X.mean(axis=0, keepdims=True)
std = X.std(axis=0, keepdims=True)

# Постоянный столбец имеет стандартное отклонение 0.
# После вычитания среднего он должен остаться нулевым.
safe_std = np.where(std == 0, 1.0, std)

X_scaled = (X - mean) / safe_std
```

Этот пример предполагает непустые конечные данные без пропусков. Для постоянного признака результат равен нулю; его стандартное отклонение после преобразования остаётся нулевым. Для остальных признаков оно примерно равно единице.

**27. Порядок проверки ошибок**

При неожиданном результате сначала проверьте структуру данных. Затем проверьте правила операции. После этого проверьте значения.

```text
1. shape → совместимы ли формы?
             ↓
2. dtype → подходит ли тип для результата?
             ↓
3. axis → по какой оси идёт вычисление?
             ↓
4. память → копия это или представление?
             ↓
5. значения → есть ли NaN, inf или переполнение?
```

```python
print(a.shape)
print(a.dtype)
print(a.ndim)

# Для числовых массивов:
print(np.isnan(a).any())

```

Не используйте `reshape()` только для устранения сообщения об ошибке. Сначала определите смысл каждой оси. Совместимая форма ещё не означает правильное вычисление.

**27 в каких случаях NumPy может изменить форму без копирования данных

NumPy может изменить форму без копирования данных тогда, когда новая форма описывается тем же буфером памяти с новыми `shape` и `strides`. На практике это возможно, если элементы в буфере лежат **подряд** и в **нужном порядке**. Если буфер не подряд или порядок не совместим с новой формой, NumPy вынужден скопировать данные. Ниже — что это значит, когда срабатывает, когда нет, и как проверить.

---

## Термины (дальше использую только так)

- **Буфер памяти** — непрерывный участок памяти, где лежат числа.
- **`shape`** — кортеж длин по каждой оси.
- **`strides`** — кортеж шагов в байтах по каждой оси. Говорит, на сколько байт сдвинуться, чтобы перейти к следующему элементу по этой оси.
- **Вид (view)** — новый массив-описание того же буфера. Копии данных нет.
- **Копия (copy)** — новый буфер с независимыми данными.
- **C-порядок** — элементы лежат подряд, последняя ось меняется быстрее всех.
- **F-порядок** — элементы лежат подряд, первая ось меняется быстрее всех.

## Как устроен массив: буфер + описание

Массив в numpy — это не «таблица в памяти». Это **один плоский буфер** плюс описание, как его читать. Описание состоит из `shape` и `strides`.

Схема:

```
массив = [ буфер памяти: 1 2 3 4 5 6 7 8 ... ]
       + [ shape:   (2, 3, 4) ]
       + [ strides: (96, 32, 8) ]   <- в байтах для int64
```

Чтобы достать элемент `c[i, j, k]`, numpy вычисляет смещение в буфере:

```
смещение = i*strides[0] + j*strides[1] + k*strides[2]
```

Схема вычисления:

```
c[1, 2, 3]  ->  1*96 + 2*32 + 3*8  =  96 + 64 + 24  =  184 байта
                (184 / 8 = 23-й элемент буфера, счёт с 0)
```

**Изменение формы без копии** — это замена `shape` и `strides` при том же буфере. Данные не двигаются.

Схема:

```
до:     shape (24,)   strides (8,)
после:  shape (4, 6)  strides (48, 8)
буфер:  тот же самый
```

## Условие, при котором копия не нужна

Копия не нужна, если новый массив можно описать теми же байтами буфера, читая их в другом порядке. Формально: элементы должны лежать в буфере **подряд** (без «дыр») и в порядке, совместимом с новой `shape`.

Два практических случая:

**Случай A. Буфер подряд, новая форма «нарезает» его без перестановки.** Тогда `reshape` и `ravel` дают вид.

**Случай B. Меняются только `strides`, буфер не трогается.** Тогда `transpose`, `swapaxes`, `.T`, базовые срезы дают вид всегда.

Схема:

```
копия не нужна, если:
  [1] буфер подряд (нет дыр)  И  новая shape совместима с порядком
  ИЛИ
  [2] операция меняет только strides (transpose, swapaxes, срез)
```

## Когда NumPy **может** вернуть вид

### `reshape` — если буфер подряд и порядок совместим

```python
a = np.arange(24)              # shape (24,), буфер подряд
b = a.reshape(4, 6)            # вид, shape (4, 6)
c = a.reshape(2, 3, 4)         # вид, shape (2, 3, 4)
print(b.base is a)             # True
print(c.base is a)             # True
```

Схема:

```
a: (24,)     strides (8,)
b: (4, 6)    strides (48, 8)     <- тот же буфер
c: (2,3,4)   strides (96,32,8)   <- тот же буфер
```

### `ravel` — если буфер подряд

```python
m = np.arange(24).reshape(4, 6)
v = m.ravel()                  # вид (если буфер подряд)
print(v.base is m)             # True
```

Оговорка: `ravel` даёт вид **не всегда**. Если буфер не подряд, `ravel` сделает копию. Подробнее ниже.

### `transpose`, `swapaxes`, `.T` — всегда

Эти операции **не двигают данные**. Они только меняют `strides`. Поэтому вид гарантирован.

```python
m = np.arange(24).reshape(4, 6)
t = m.T                        # shape (6, 4), strides переставлены
print(t.base is m)             # True
```

Схема:

```
m: shape (4, 6), strides (48, 8)
t: shape (6, 4), strides (8, 48)   <- буфер тот же, strides переставлены
```

### Базовые срезы — всегда

Срез `[a:b]`, `[:, c]`, `[::k]` возвращает вид. Данные не копируются.

```python
m = np.arange(24).reshape(4, 6)
s = m[1:3, ::2]
print(s.base is m)             # True
```

Схема:

```
m[1:3, ::2]  ->  вид: смещение + новые shape/strides, буфер тот же
```

### `np.split` — всегда

`np.split` возвращает **список видов**. Данные не копируются.

```python
parts = np.split(np.arange(24).reshape(4, 6), 2, axis=0)
print(parts[0].base is not None)   # True
```

---

## Когда NumPy **обязан** скопировать

### `flatten` — всегда копия

Это правило `flatten`: она всегда создаёт новый буфер.

```python
m = np.arange(24).reshape(4, 6)
f = m.flatten()
print(f.base)                  # None  -> копия
```

### `ravel` — если буфер не подряд

Если элементы в буфере лежат с «дырами» или в неудобном порядке, `ravel` не может вернуть вид. Тогда она делает копию.

```python
m = np.arange(24).reshape(4, 6)
t = m.T                        # shape (6, 4), буфер НЕ подряд
r = t.ravel()                  # копия, не вид
print(r.base)                  # None
```

Схема:

```
m:  буфер подряд
t = m.T:  тот же буфер, но strides (8, 48) — чтение "по столбцам"
r = t.ravel():  чтобы получить 1D подряд, нужен новый буфер -> копия
```

### `reshape` — если новая форма не совместима с текущим порядком

Тот же пример:

```python
m = np.arange(24).reshape(4, 6)
t = m.T                        # (6, 4), буфер не подряд
r = t.reshape(24)              # копия
print(r.base)                  # None
```

Схема:

```
t: shape (6,4), strides (8,48)  ->  reshape(24)  ->  нужна копия
```

Оговорка: иногда `reshape` на «неподряд» массиве всё же возвращает вид — если новая форма случайно совместима с текущими `strides`. Это редкий случай. Проверяйте через `.base`.

### Fancy indexing — всегда копия

Индексация списком индексов или массивом индексов всегда копирует.

```python
a = np.arange(10)
b = a[[0, 2, 5]]               # копия
print(b.base)                  # None
```

### Логическая маска — всегда копия

```python
a = np.arange(10)
b = a[a > 5]                   # копия
print(b.base)                  # None
```

### Арифметика — всегда новый массив

```python
a = np.arange(10)
b = a + 1                      # новый буфер
print(b.base)                  # None
```

## Сводная схема

```
операция                вид/копия                 условие
----------------------  ------------------------  ------------------------------
reshape                 вид, если возможно        буфер подряд + порядок совместим
reshape                 копия иначе               буфер не подряд
ravel                   вид, если возможно        буфер подряд
ravel                   копия иначе               буфер не подряд
flatten                 ВСЕГДА копия              —
transpose / .T          всегда вид                —
swapaxes                всегда вид                —
базовый срез [a:b]      всегда вид                —
срез с шагом [::k]      всегда вид                —
np.split                всегда вид (список)       —
fancy indexing a[[..]]  всегда копия              —
логическая маска a[m]   всегда копия              —
арифметика a + 1        всегда новый массив       —
```

## Почему это работает: `strides` и порядок в памяти

`strides` говорит, как «шагать» по буферу. Если новая `shape` и новые `strides` дают тот же набор смещений, что и старые, — данные читаются корректно без перестановки. Тогда копия не нужна.

Пример для `(24,)` → `(4, 6)`:

```
старое:  shape (24,)   strides (8,)
         смещения: 0, 8, 16, 24, 32, ...

новое:   shape (4, 6)  strides (48, 8)
         смещения: i*48 + j*8
         для i=0: 0, 8, 16, 24, 32, 40         <- те же первые 6
         для i=1: 48, 56, 64, 72, 80, 88      <- следующие 6
         ...

набор смещений тот же, порядок тот же -> вид возможен
```

Схема наоборот, для `m.T` → `reshape(24)`:

```
m.T: shape (6, 4), strides (8, 48)
     смещения: 0, 48, 96, 144, 8, 56, ...
     порядок смещений НЕ возрастающий -> нельзя прочитать одним проходом
     reshape(24) требует подряд -> нужна копия
```

## Как проверить: `.base` и `flags`

**Атрибут `.base`.** Если `.base is not None` — это вид (или часть цепочки видов). Если `.base is None` — самостоятельный буфер (копия или исходник).

```python
b = a.reshape(4, 6)
print(b.base is a)          # True  -> вид

f = a.reshape(4, 6).flatten()
print(f.base)               # None  -> копия
```

Схема:

```
.base is not None  ->  вид
.base is None      ->  самостоятельный буфер
```

**Флаг `OWNDATA`.** Показывает, владеет ли массив своим буфером.

```python
b = a.reshape(4, 6)
print(b.flags['OWNDATA'])   # False -> не владеет (вид)

f = a.flatten()
print(f.flags['OWNDATA'])   # True  -> владеет (копия)
```

Схема:

```
OWNDATA = True   ->  массив владеет буфером (копия или исходник)
OWNDATA = False  ->  это вид
```

**Флаг `C_CONTIGUOUS`.** Показывает, лежит ли буфер подряд в C-порядке.

```python
m = np.arange(24).reshape(4, 6)
print(m.flags['C_CONTIGUOUS'])    # True   -> буфер подряд
print(m.T.flags['C_CONTIGUOUS'])  # False  -> после transpose не подряд
```

Схема:

```
C_CONTIGUOUS = True   ->  буфер подряд, reshape/ravel дадут вид
C_CONTIGUOUS = False  ->  буфер не подряд, reshape/ravel могут дать копию
```

---

## Практическое правило

Перед `reshape`/`ravel` на массиве, который прошёл через `transpose`, `swapaxes` или срез с шагом, проверьте `C_CONTIGUOUS`. Если `False` и форма важна — либо сразу делайте `.copy()`, либо принимайте, что numpy сделает копию сам.

Схема решения:

```
нужно изменить форму?
   |
   +-- массив C_CONTIGUOUS? --да--> reshape/ravel дают вид
   |                          нет
   |                           |
   |                           +--> reshape/ravel дадут копию
   |                                (или используйте .copy() явно)
   |
   +-- нужен ли вид или копия?
        вид   -> reshape/ravel без .copy()
        копия -> .copy() или flatten
```

## Итог в одной схеме

```
может без копии, если:
  [1] буфер подряд И новая shape совместима с порядком   (reshape, ravel)
  [2] операция меняет только strides                     (transpose, swapaxes, .T, срез)

обязан копировать:
  [1] flatten
  [2] ravel/reshape на неподрядном буфере
  [3] fancy indexing
  [4] логическая маска
  [5] арифметика

проверка:
  .base is not None        -> вид
  .flags['OWNDATA'] False  -> вид
  .flags['C_CONTIGUOUS']   -> подряд ли буфер
```

Правило для запоминания: **изменение формы — это изменение описания (`shape` + `strides`), а не данных. Копия нужна только когда данные в буфере лежат не так, как требует новая форма.**
