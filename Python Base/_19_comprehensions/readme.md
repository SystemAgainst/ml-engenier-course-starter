# Итоги: comprehensions

- List comprehension — компактный способ создать список из итерируемого объекта; он часто заменяет цикл `for` с накоплением через `append()`. Формула: `[выражение for элемент in последовательность]`.
- Выражение, то есть значение, которое попадёт в список, всегда стоит перед `for`. Например, `[x ** 2 for x in range(10)]` создаёт список квадратов.
- Фильтр `if` без `else` указывается после `for`: `[x ** 2 for x in range(10) if x % 2 == 0]`. Он определяет, какие элементы `включить`.
- Условное выражение `if/else` выбирает значение для каждого элемента и находится в начале: `["even" if num % 2 == 0 else "odd" for num in numbers]`. Решает, какое значение положить в список. Он и есть часть ВЫРАЖЕНИЯ, поэтому идёт в начало.
- Dict comprehension создаёт словарь с помощью фигурных скобок и пары ключ–значение: `{x: x ** 2 for x in range(10)}`.
- Вложенные comprehensions позволяют компактно выполнять вложенные циклы; например, построить транспонированную матрицу. Внешний comprehension соответствует внешнему циклу, внутренний — внутреннему.
- При чтении или записи comprehension полезно различать две задачи: «что добавить в результат?» (выражение в начале) и «какие элементы оставить?» (фильтр `if` в конце).
