# Итоги: лямбда-функции в Python

В рамках этих файлов я научился, что такое лямбда-функции и как они помогают писать короткий и удобный код для простых операций.

## 1. Что такое лямбда-функция

Лямбда-функция — это анонимная функция, то есть функция без имени. Она обычно используется там, где нужно быстро выполнить простое действие и не создавать отдельную функцию.

Пример:

```python
sort_by_len_lambda = lambda element: len(element)
```

Здесь `lambda` принимает один аргумент `element` и возвращает длину строки.

## 2. Сравнение с обычной функцией

Обычная функция:

```python
def sort_by_len(element: str) -> int:
    return len(element)
```

Лямбда-эквивалент:

```python
lambda element: len(element)
```

Обе версии работают одинаково, но лямбда удобна для коротких операций, особенно внутри других функций.

## 3. Использование в `sorted()`

Я научился применять лямбда в сортировке списка:

```python
fruits = ["banana", "apple", "cherry", "date"]
sorted_fruits = sorted(fruits, key=lambda element: len(element))
```

Так можно сортировать строки по длине без создания отдельной функции.

## 4. Использование в `max()`

Лямбда удобно использовать вместе с `max()`, чтобы найти элемент по нужному критерию:

```python
longest_word = max(fruits, key=lambda el: len(el))
```

Это позволяет выбрать элемент с максимальной длиной строки.

## 5. Сортировка по нескольким критериям

Я также научился сортировать объекты по нескольким параметрам через кортеж внутри `lambda`:

```python
sorted_people = min(people, key=lambda el: (el['age'], el['name']))
```

Здесь сначала сравнивается возраст, а если он одинаковый — имя. Это позволяет определить минимальный элемент по нескольким полям.

## 6. Когда удобно использовать лямбда

Лямбда-функции особенно полезны, когда:

- нужно быстро задать правило сортировки;
- нужно выбрать элемент по условию;
- функция используется один раз и не требует повторного использования;
- код должен быть кратким и читабельным.

## 7. Что важно запомнить

- `lambda` — это анонимная функция.
- Она подходит только для простых выражений.
- Часто используется в `sorted()`, `max()`, `min()`, `filter()` и т.д.
- Ключевое преимущество — компактность и удобство в одноразовых задачах.

Итог: я научился использовать лямбда-функции для короткой и эффективной обработки данных, особенно при сортировке и выборе элементов по условию. Это помогает писать более лаконичный и понятный код.
