# Итоги: работа с датой и временем в Python

В этом примере я научился:

- Получать текущее время в UTC и локальное время с помощью `datetime`.
- Создавать объекты `datetime` и `date`, а также обращаться к компонентам даты и времени: году, месяцу, дню, часам, минутам, секундам и микросекундам.
- Преобразовывать дату и время в строку ISO 8601 с помощью `isoformat()`.
- Получать только дату из объекта `datetime` и текущую дату через `date.today()`.
- Вычислять дату или время в прошлом с помощью `timedelta`.
- Форматировать дату и время с помощью `strftime()`.
- Создавать объект `datetime` из ISO-строки с помощью `fromisoformat()`.
