# Итоги: обработка ошибок с помощью `try` / `except`

В рамках этих файлов я научился, как защищать программу от ошибок и корректно реагировать на исключения.

## 1. Что такое `try` / `except`

Блок `try` позволяет выполнить код, в котором может произойти ошибка. Если ошибка возникает, программа не падает, а переходит в блок `except`, где можно обработать исключение.

Пример:

```python
try:
    print(find_average(numbers=[]))
except ZeroDivisionError:
    print("The list is empty")
```

Это особенно полезно, когда нужно избежать аварийного завершения программы.

## 2. Обработка деления на ноль

Я научился понимать, что при делении на ноль возникает исключение `ZeroDivisionError`.

```python
def find_average(*, numbers: list) -> float:
    return sum(numbers) / len(numbers)
```

Если список пустой, то выражение `len(numbers) == 0`, и программа пытается выполнить деление на ноль. Без обработки программа завершится с ошибкой. С `try` / `except` можно вывести понятное сообщение вместо падения.

## 3. Почему это важно в реальном коде

Обработка исключений помогает:

- не останавливать программу при ошибках;
- показывать пользователю понятное сообщение;
- отлавливать нестандартные ситуации;
- делать код устойчивым и безопасным.

## 4. Обработка ошибок при работе с сетью

Во втором файле я увидел пример работы с HTTP-запросом через библиотеку `requests`.

```python
try:
    response = requests.get(url, params)
    bitcoin_price = response.json()["price"]
    price = float(bitcoin_price)
    print(price)
except requests.exceptions.ConnectionError as error:
    print(f"Something goes wrong: {error}")
```

Здесь я научился, что при проблемах с подключением к серверу можно перехватить ошибку `ConnectionError` и не дать программе упасть.

## 5. Что такое `Exception`

Ошибка в Python — это объект исключения. Для разных видов ошибок используются разные типы, например:

- `ZeroDivisionError` — деление на ноль;
- `ConnectionError` — проблемы с подключением;
- `FileNotFoundError` — файл не найден.

Это позволяет аккуратно обрабатывать разные сценарии.

## 6. Практическое применение

`try` / `except` полезен в задачах:

- при работе с файлами;
- при запросах к API;
- при чтении пользовательского ввода;
- при обработке данных, где возможны пустые значения или сбои.

- выводить понятные сообщения вместо неожиданных падений.

Итог: обработка ошибок — важный навык в Python, который помогает писать надежный и профессиональный код.
