# Итоги: Telegram-бот с ценами криптовалют

В этом проекте я научился:

- Загружать токен Telegram-бота из `.env` с помощью `python-dotenv`.
- Создавать бота с помощью `TeleBot`.
- Обрабатывать команду `/start` и показывать пользователю клавиатуру с кнопками.
- Связывать названия криптовалют с тикерами Binance с помощью словаря.
- Получать цену криптовалюты через Binance API и обрабатывать JSON-ответ.
- Отправлять цену в чат и запускать бота через `infinity_polling()`.
