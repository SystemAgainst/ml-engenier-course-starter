# Итоги: HTTP-запросы с `requests`

- `requests.get(url, params=...)` отправляет GET-запрос; параметры запроса передаются через `params`, например для получения пары `BTCUSDT`.
- Ответ сервера — объект `Response`. `response.content` содержит тело ответа в байтах, а `response.json()` разбирает JSON и возвращает соответствующие Python-объекты: словарь или список.
- Данные из JSON можно обрабатывать как обычные Python-структуры: например, взять поле `price` и преобразовать строку с ценой в число через `float()`.
- Если отправить запрос без `params`, API возвращает список котировок. Его можно перебрать, найти словарь с нужным `symbol` (например, `ETHUSDT`) и получить цену.
- Повторные запросы удобно выполнять в цикле, накапливать результаты в списке и анализировать их с помощью `len()`, `max()` и `min()`. `time.sleep(1)` делает паузу между запросами.
