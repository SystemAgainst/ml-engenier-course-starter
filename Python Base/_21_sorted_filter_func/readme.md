# Итоги: `sorted()` и `filter()`

В рамках этих файлов я научился, как работать со встроенными функциями Python для обработки списков и данных.

## 1. `sorted()` — сортировка данных

- `sorted()` позволяет сортировать список без изменения исходного массива.
- После сортировки создаётся новый список, а оригинальный остаётся прежним.
- По умолчанию сортировка идёт по возрастанию.
- Если передать `reverse=True`, список сортируется в обратном порядке.

Пример:

```python
fruits = ['banana', 'apple', 'cherry', 'date']
sorted_fruits = sorted(fruits)
```

Результат: `['apple', 'banana', 'cherry', 'date']`.

## 2. `key` — сортировка по кастомному правилу

- `sorted()` поддерживает параметр `key`, который принимает функцию.
- Эта функция задаёт правило, по которому будет происходить сортировка.
- Важно: функция передаётся без вызова, то есть без `()`. 

Пример:

```python
def sort_by_len(element: str) -> int:
    return len(element)

new_sorted_fruits = sorted(fruits, key=sort_by_len)
```

Так можно сортировать строки по длине, а не только по алфавиту.

## 3. Сортировка сложных объектов

Я научился сортировать списки словарей по значениям ключей.

```python
def sort_by_age(person: dict) -> int:
    return person['age']
```

Так можно легко сортировать данные по возрасту, зарплате, имени и другим полям.

Также можно сортировать по нескольким критериям сразу, возвращая кортеж:

```python
def sort_by_age_name(person: dict) -> tuple[int, str]:
    return person['age'], person['name']
```

Это позволяет сначала сортировать по одному параметру, а затем — по второму.

## 4. `filter()` — отбор элементов по условию

- `filter()` используется для отбора элементов, удовлетворяющих условию.
- В функцию `filter()` передаётся предикат — функция, которая возвращает `True` или `False`.
- Результат `filter()` — это объект `filter`, который нужно преобразовать в список, если нужно увидеть все значения.

Пример:

```python
def is_even(n: int) -> bool:
    return n % 2 == 0

filtered_numbers = list(filter(is_even, numbers))
```

Результат: `[2, 4, 6, 8]`.

## 5. Практическое применение

В реальных задачах `filter()` помогает:

- отбирать взрослых пользователей из списка;
- выбирать только чётные числа;
- оставлять объекты, соответствующие определённым условиям;
- подготавливать данные перед дальнейшей обработкой.

## 6. Что важно запомнить

- `sorted()` создаёт новый отсортированный список.
- `filter()` создаёт фильтрованный набор данных, а не меняет исходный список.
- `key` позволяет задавать гибкую логику сортировки.
- `reverse=True` переключает сортировку на обратный порядок.
- Для сложных данных удобно использовать функции, которые возвращают значения для сравнения.
