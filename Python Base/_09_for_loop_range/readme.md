# Итоги: циклы `for` и `range`

- `for` перебирает элементы списка или символы строки; вложенные циклы позволяют перебирать элементы внутри элементов.
- `range(stop)`, `range(start, stop)` и `range(start, stop, step)` создают последовательность чисел. `stop` не включается; шаг может быть отрицательным. Чтобы получить список, можно использовать `list(range(...))`.
- `range(len(список))` позволяет перебирать индексы и изменять элементы списка по индексу.
- При `for num in numbers` переменная `num` получает значение элемента. `int` неизменяемый, поэтому `num += 1` присваивает новое значение только переменной, не меняя список. Изменение через `numbers[i] += 1` записывает значение в сам список.
- `continue` пропускает оставшуюся часть текущей итерации, а `break` завершает цикл.
- В цикле можно подсчитывать подходящие элементы и сохранять их индексы.
- Вложенные циклы подходят для построения таблицы умножения; f-строки помогают форматировать вывод.
