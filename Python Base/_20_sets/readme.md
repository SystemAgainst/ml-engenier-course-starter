# Итоги: множества (`set`)

- Множество хранит только уникальные элементы. Повторный вызов `.add()` для уже присутствующего значения не добавляет дубликат.
- У множества нет фиксированного порядка элементов; сравнение множеств проверяет состав, а не порядок.
- Создать пустое множество можно через `set()`. `{}` создаёт пустой словарь.
- Элементы добавляют методом `.add()`, а удаляют методом `.remove()` по значению, не по индексу.
- Множества поддерживают операции объединения (`union`), пересечения (`intersection`) и разности (`difference`).
- Set comprehension позволяет создать множество по выражению, например `{x**2 for x in range(5)}`.
- Преобразование списка в множество удаляет дубликаты: `set(numbers)`. Чтобы получить список уникальных значений, множество можно преобразовать обратно через `list()`. Порядок элементов при этом не гарантируется.
- `set` и `dict` основаны на хэш-таблицах, поэтому обычно быстро проверяют наличие элемента или ключа. **Хэшируемый объект** — объект с хэш-значением, которое не меняется в течение его жизни и позволяет сравнивать его с другими объектами; поэтому объект можно безопасно использовать как элемент `set` или ключ `dict`. Например, `int` и `str` хэшируемы, а `list` и `dict` — нет. В `set` хранятся уникальные хэшируемые значения, а в `dict` — пары «ключ — значение» с уникальными хэшируемыми ключами. Пустое множество создают как `set()`, а `{}` — это пустой словарь.
