## Списки (`list`)

- Структура для хранения **упорядоченных последовательностей**: элементы имеют определённые позиции, но не обязательно отсортированы.
- Можно хранить разные типы данных: `int`, `str`, `bool`, другие списки и т. д.
- Для однотипных данных обычно удобнее хранить один тип: это упрощает обработку.
- Повторяющиеся элементы допустимы.
- `len(my_list)` возвращает количество элементов.
- `x in my_list` проверяет наличие элемента, `x not in my_list` — отсутствие.
- `list("hello")` создаёт список символов: `['h', 'e', 'l', 'l', 'o']`.

### Сравнение списков

- `==` сравнивает длину и соответствующие элементы. Порядок важен:
  - `[1, 2, 3] == [1, 3, 2]` → `False`.
  - `[1, 2, 3] == [1, 2, 3]` → `True`.
- `==` проверяет равенство значений, а `is` — являются ли списки одним объектом.
- Пустой список даёт `bool([]) == False`; любой непустой — `True`, даже `[0]` или `[False]`.

### Изменение списка — мутация

- Список **изменяемый**: его содержимое можно менять без создания нового списка.
- В примере с `fruits.append("watermelon")` изменился исходный список `fruits`: в него добавился элемент.
- Если два имени ссылаются на один список, изменения видны через оба имени.
- `my_list.copy()` создаёт поверхностную копию: вложенные объекты остаются общими.

### Основные операции

- `append(x)` добавляет **один объект** в конец.
- `extend(other)` добавляет **все элементы** другой коллекции.
- `pop()` удаляет и возвращает последний элемент; `pop(i)` — элемент с индексом `i`.
- `reverse()` разворачивает текущий порядок.
- `sort()` сортирует исходный список; `sort(reverse=True)` — по убыванию.
- `sorted(my_list)` возвращает новый отсортированный список.
- `list1 + list2` создаёт новый объединённый список.
- `append()`, `extend()`, `reverse()` и `sort()` возвращают `None`: не нужно присваивать их результат обратно списку.
- `max()`, `min()` и `sum()` находят максимум, минимум и сумму. Суммирование смеси чисел и строк вызовет `TypeError`.

## Строки и списки

- Строки **неизменяемые**: `replace()` возвращает результат, не изменяя исходную строку.
- `split()` разбивает строку на список частей.
- `" ".join(my_list)` соединяет строки из списка через пробел. Все элементы должны быть строками.
- В f-строке выражения записываются в `{...}`.
- Для переноса строки используется `\n`, а не `/n`.

## Исправления в примерах урока

- После `fruits = ['apple', 'banana', 'cherry']` вызов `pop()` вернёт `'cherry'`, а в списке останутся `['apple', 'banana']`.
- После такого же присваивания и `extend(['fig', 'grape'])` получится `['apple', 'banana', 'cherry', 'fig', 'grape']`.
- Каждое новое присваивание `fruits = [...]` перепривязывает имя к новому списку: прежние добавления не переносятся.
