# Итоги: расширенные возможности функций

- `*args` позволяет передать функции произвольное количество позиционных аргументов. Внутри функции они доступны как кортеж.
- `**kwargs` собирает произвольное количество именованных аргументов в словарь. Их можно перебирать через `.items()`.
- Оператор `*` при вызове распаковывает последовательность в позиционные аргументы, а `**` распаковывает словарь в именованные аргументы.
- Можно сочетать обычные параметры, `*args`, именованные параметры со значением по умолчанию и `**kwargs`, соблюдая порядок параметров в объявлении функции.
- Функция может вернуть несколько значений, например словарь и признак изменения. Python упаковывает их в кортеж, который можно распаковать в отдельные переменные.
- В примере `modify_dict` словарь обновляется переданными именованными значениями, а вместе с ним возвращается булев признак, были ли изменения.
