
# Итоги: цикл `while`

- `while` повторяет блок кода, пока условие истинно. В отличие от `for`, который обычно перебирает элементы последовательности, `while` подходит, когда число повторений заранее неизвестно и цикл зависит от условия.
- Условие цикла должно со временем стать ложным, иначе цикл будет бесконечным. Для выхода из цикла можно использовать `break`.
- Цикл может завершиться и после изменения состояния, например пока список не опустеет: `while my_list` вместе с `my_list.pop()`.
- `while True` создаёт цикл без конечного условия; в примере ввод продолжается, пока пользователь не введёт `quit`.
- На примере симуляции мартингейла применены цикл `while` для игры до потери средств и цикл `for` для повторения симуляции заданное число раз.
- Для моделирования случайных событий можно использовать `random.choice`; функции помогают разделить логику броска монеты, одной игры и серии игр.
- Счётчики и состояние игры (деньги, ставка) обновляются на каждой итерации. Условия ограничивают максимальную ставку и не дают поставить больше имеющихся средств.
