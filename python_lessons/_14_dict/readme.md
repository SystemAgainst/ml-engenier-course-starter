# Итоги: словари (`dict`)

- Словарь хранит данные в парах «ключ — значение». Значение получают по ключу, например `person["name"]`; отсутствующий ключ вызывает `KeyError`. Метод `.get()` позволяет безопасно получить значение и при необходимости указать значение по умолчанию.
- В словарь можно добавлять новые пары и обновлять существующие. При объединении словарей через `.update()` или оператор `|` совпадающие ключи получают значение из второго словаря.
- Для перебора словаря можно использовать `.items()` (ключи и значения), `.keys()` (ключи) и `.values()` (значения). Пары из `.items()` удобно распаковывать: `for key, value in person.items()`.
- Равенство словарей определяется совпадением пар «ключ — значение», а не порядком их добавления.
- Словари удобно использовать для структурированных записей, например хранить имя, фамилию и оценки студента. Можно перебирать список таких словарей, рассчитывать средние оценки и находить всех студентов с наивысшим результатом.

## Отличия `dict`, `list` и `tuple`

- `list` — упорядоченная изменяемая последовательность; элементы доступны по индексам. Подходит для набора элементов, который нужно менять.
- `tuple` — упорядоченная неизменяемая последовательность; элементы также доступны по индексам. Подходит для фиксированного набора значений.
- `dict` — изменяемое сопоставление ключей и значений; к значению обращаются по ключу, а не по позиции. Подходит для именованных полей и быстрого поиска значения по ключу.
