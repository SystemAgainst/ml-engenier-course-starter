# Итоги: модули и импорты

- Модуль — Python-файл с кодом, который можно подключить в другом файле через `import` или `from ... import ...`.
- Можно импортировать модуль целиком (`import random`) и обращаться к его функциям через имя модуля (`random.choice()`), либо импортировать отдельные функции (`from ... import add`).
- `as` задаёт импорту псевдоним, например `from ... import add as addition`.
- Импорт модуля (`from _17_import import math_operations`) позволяет обращаться к его функциям через имя модуля (`math_operations.add()`).
- `from ... import *` импортирует имена напрямую, но затрудняет понимание их источника, поэтому такой способ не рекомендуется.
- Файл `__init__.py` обозначает каталог как пакет Python и выполняется при импорте пакета. В нём можно оставить его пустым или определить, что пакет предоставляет для импорта. В современных версиях Python некоторые каталоги могут работать как пакеты без этого файла, но `__init__.py` полезен для обычной структуры пакета и явной инициализации.
- В примерах используются стандартная библиотека Python (`random`, `builtins`) и собственный модуль `math_operations.py`.
- `globals()` показывает имена, доступные в глобальной области текущего модуля, а `dir()` — имена, определённые в объекте или модуле. Встроенные функции и типы, например `print`, `range`, `dict` и `list`, доступны через `builtins`.
