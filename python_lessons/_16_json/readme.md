# Итоги: JSON

- JSON — текстовый формат для хранения и обмена структурированными данными, например информацией о книге.
- Модуль `json` преобразует Python-объекты в JSON-строку с помощью `json.dumps()`. Результат имеет тип `str`.
- `json.loads()` разбирает JSON-строку и создаёт соответствующий Python-объект, например словарь.
- Словари с числами, строками и списками можно сериализовать в JSON и затем восстановить из него. JSON представляет собой текст, а не сам Python-словарь.
