# Индексы и срезы

- Индексы обращаются к отдельным элементам: нумерация начинается с `0`, отрицательные индексы отсчитываются с конца. Если индекс выходит за границы списка, возникает `IndexError`.
- Элементы списка можно изменять по индексу и менять местами.
- Срез `список[start:stop:step]` выбирает элементы до `stop` — конечный индекс не включается. Начало, конец и шаг можно опускать; отрицательный шаг позволяет читать элементы в обратном порядке.
- Срезы применяются и к строкам.
- Развернуть список можно тремя способами: `список[::-1]` создаёт новый список, `список.reverse()` изменяет исходный, а `reversed(список)` возвращает итератор.
